# Primal Defiance

Melty mashup design scaffold for **Dawn of Defiance** (host) + **Ancestors: The Humankind Odyssey** (companion).

## First playable slice
- Host: Dawn of Defiance
- Companion: Ancestors: The Humankind Odyssey
- Mode: single-player first release
- Core loop: gather/hunt/craft in Dawn of Defiance while reading the player's real Ancestors evolution data to gate a small set of survival upgrades.
- First-minute goal: collect basic materials, craft a primitive tool, make a first hunt/kill, then unlock the first evolution-linked upgrade.
- No game assets are redistributed; companion data is read from the player's installed copy.

## Current status
This repository is a source/design scaffold only. It has not been compiled, launched, or tested against local game installations, and it is not yet a publishable Melty release.
